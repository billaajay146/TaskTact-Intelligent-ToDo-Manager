# TaskTact – Intelligent To-Do Manager 📝

A simple and interactive Python-based task management application that helps users organize, update, categorize, and track their daily tasks through a menu-driven console interface.

## 📌 Project Overview

TaskTact is a console-based To-Do Manager developed using Python. It allows users to manage tasks efficiently by adding new tasks, modifying existing tasks, deleting completed or unnecessary tasks, organizing tasks by category, and tracking task completion.

The application uses JSON file storage to preserve tasks between program executions.

## 🎯 Objectives

- Simplify daily task management.
- Organize tasks using categories and priorities.
- Track pending and completed tasks.
- Provide an easy-to-use menu-driven interface.
- Store task information persistently using JSON.
- Practice Python functions, lists, dictionaries, loops, and file handling.

## ✨ Features

- **Add Tasks:** Create new tasks with relevant details.
- **View Tasks:** Display all saved tasks.
- **Update Tasks:** Modify existing task information.
- **Delete Tasks:** Remove unwanted tasks.
- **Categorize and Filter:** Organize tasks by category, status, or priority.
- **Mark as Completed:** Update task completion status.
- **Task Summary:** View an overview of task progress.
- **Persistent Storage:** Save and load tasks using a JSON file.

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/billaajay146/TaskTact-Intelligent-ToDo-Manager.git
```

### 2. Navigate to the project folder

```bash
cd TaskTact-Intelligent-ToDo-Manager
```

### 3. Run the application

```bash
python TaskTact_Final.py
```

On some Windows systems, use:

```bash
py TaskTact_Final.py
```

If your Python file has a different name, replace `TaskTact_Final.py` with the actual filename.

## 🖥️ How to Use

1. Run the Python program in a terminal.
2. Select an option from the main menu.
3. Add tasks and enter the requested details.
4. View, update, delete, categorize, or filter tasks as needed.
5. Mark tasks as completed when finished.
6. View the task summary to monitor progress.
7. Select the exit option to close the application.
